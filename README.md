# 🐍 Basic Python Projects

A collection of beginner-friendly Python projects created to practice programming fundamentals, problem-solving, GUI development, file handling, automation, and basic application development.

This repository represents my journey of learning Python by building small and practical projects.

## 📌 About This Repository

This repository contains multiple Python projects developed while learning and practicing Python.

Instead of only studying Python concepts theoretically, I used these projects to understand how different programming concepts can be applied to real-world applications.

The projects range from simple command-line programs and games to GUI-based applications, file management tools, QR-code projects, and text-processing utilities.
